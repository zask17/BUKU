## 🧠 Key Concepts Quick Reference

### Shopping Cart
- **Location:** `resources/views/guest/order.blade.php`
- **Technology:** JavaScript, jQuery
- **Data:** Client-side array
- **Functions:** `tambahItem()`, `renderKeranjang()`, `hapusItem()`

### Checkout Process
- **Location:** `app/Http/Controllers/Guest/KantinController.php`
- **Method:** `checkout()`
- **Flow:** Validate → Create pesanan → Create details → Generate snap token
- **Response:** JSON dengan snap_token

### Payment Processing
- **Gateway:** Midtrans Snap API
- **Location:** `resources/views/guest/order.blade.php` (client-side)
- **Methods:** `window.snap.pay()`
- **Callbacks:** onSuccess, onPending, onError

### Webhook Handling
- **Endpoint:** `/midtrans/callback`
- **Method:** `KantinController@callback()`
- **Verification:** SHA512 signature
- **Updates:** status_bayar, metode_bayar

### Database Model
- **Vendors:** 2 (Kantin Sehat, Warung Berkah)
- **Menus:** 5 items
- **Orders:** Tracked di tabel pesanan
- **Items:** Tracked di tabel detail_pesanan
